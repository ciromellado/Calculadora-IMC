# 🩺 Calculadora de IMC (PWA)

La aplicación **Calculadora de IMC** ha sido desarrollada bajo la arquitectura de una Progressive Web App (PWA), lo que le otorga características técnicas excepcionales pensadas para el entorno clínico: segura y súper liviana.

---

## ✨ Características Principales

* 📊 **Resultados instantáneos y precisos:** Cálculo automatizado del IMC en segundos, adaptado con los estándares internacionales más estrictos.
* 👶 **Enfoque Pediátrico Especializado:** Incorpora curvas y percentiles de crecimiento avalados por la OMS para evaluar de forma correcta a niños y adolescentes.
* 📱 **Diseño 100% Instalable (PWA):** Instálala directamente en la pantalla de inicio de tu teléfono, tablet o computadora como si fuera una aplicación nativa.
* 📶 **Funcionalidad Sin Conexión (Offline):** No depende de una red Wi-Fi o datos móviles activos para funcionar, ideal para consultorios o zonas con señal intermitente.

---

## 🚀 Uso

Puedes utilizar esta aplicación directamente desde el navegador o instalarla en tu dispositivo para un acceso rápido y sin conexión.
